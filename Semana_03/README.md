# Semana 03 - Matrícula de Estudiantes

## Descripción

Programa desarrollado en Kotlin para gestionar la matrícula de estudiantes.

## Funcionalidades

- Registro de estudiantes.
- Selección de turno: mañana, tarde y noche.
- Descuentos según el turno.
- Categoría de estudiante: ordinario o becado.
- Registro de cursos y créditos.
- Cálculo del costo de matrícula.
- Cálculo del IGV.
- Cálculo del total a pagar.
- Cálculo de cuotas.
- Control de aforo máximo.

## Tecnología

- Kotlin
- Android Studio
