# Semana 01 — Hola Mundo en Android

Primer laboratorio del curso de **Desarrollo de Aplicaciones Móviles**, enfocado en la creación y ejecución de una aplicación básica utilizando Kotlin y Jetpack Compose.

## Objetivo

Familiarizarse con el entorno de Android Studio y la estructura inicial de un proyecto Android desarrollado con Jetpack Compose.

## Desarrollo

Durante el laboratorio se trabajó con:

* Creación de un proyecto Android.
* Uso básico de Kotlin.
* Creación de una interfaz con Jetpack Compose.
* Ejecución de la aplicación en Android.
* Uso de Git y GitHub para el control de versiones.

## Tecnologías

`Kotlin` · `Android Studio` · `Jetpack Compose` · `Gradle`
